# 🏥 Medical Management System

A full-stack web application designed to manage pharmacy inventory, medicine records, and stock details.

🔗 **Live Demo:** [medical-management-app.vercel.app](https://medical-management-app.vercel.app)

---

## 🛠️ Tech Stack
- **Frontend:** React, HTML5, CSS3, JavaScript
- **Backend:** Java Spring Boot, REST APIs, Maven
- **Deployment:** Vercel (Frontend)

---

## ✨ Features
- **Medicine Directory:** View and manage medicine records, dosage details, stock quantities, and prices.
- **Stock Tracking:** Monitor available medicine quantities and low stock alerts.
- **Responsive Interface:** Clean modern UI built with React.
